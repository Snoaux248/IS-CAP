# Influencer Sponsorship & Campaign Analytics Platform
This is a comprehensive mySQL database utilizing proper implementation and development technique. 
First starting with problem identification, ER/EER diagrams, then a relational Schema based upon BCNF (Boyce Codd Normal Form). and finaly implementation of actual queries.
This was a several stage iterative process. and sholu be noted that the EER and ER diagrams do not align perfectly with report diagrams due to discoveries upon actual implementation namely a composite key cannot have a null attribute
